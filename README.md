# Ken's Weather

An ad-free, single-page weather app: current conditions, sunrise and sunset, hourly and 7-day forecasts, National Weather Service alerts, radar, and National Hurricane Center storm tracking.

Data sources (all free, no keys):
- Forecast and city search: [Open-Meteo](https://open-meteo.com/)
- Severe weather alerts: [National Weather Service API](https://www.weather.gov/documentation/services-web-API)
- Radar: [RainViewer](https://www.rainviewer.com/api.html) over a CARTO / OpenStreetMap basemap (Leaflet)
- Tropical storms: [National Hurricane Center](https://www.nhc.noaa.gov/)

Hosted with GitHub Pages from `index.html` on `main`.
